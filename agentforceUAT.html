Pruebas UAT - Agentforce

Matriz de Pruebas: Acceder a Dropbox

1. Consideraciones Generales

  • Estas pruebas deben ejecutarse como si fueras un cliente real, escribiendo de forma natural.
  • El objetivo es validar si la experiencia y el resultado son los esperados, no evaluar aspectos técnicos.

2. Canales Disponibles para Pruebas

WhatsApp

Número habilitado: 56 5785 5508

Este número es temporal y exclusivo para UAT.

Reiniciar conversación en WhatsApp:

  1. Escribe la palabra "stop"
  2. Espera la confirmación
  3. Inicia nuevamente la conversación

Esto permite ejecutar varios casos con el mismo número.

Chat Web

Accede al chat web habilitado para pruebas (En la burbuja inferior derecha).

Reiniciar conversación en Chat Web:

  1. Da clic en "Finalizar conversación"
  2. Recarga la página
  3. Inicia una nueva conversación

5. Pruebas con Otros Modelos

  • Puedes preguntar por otros modelos distintos a los listados.
  • Si el modelo no tiene documentación de soporte, el agente:
    • No podrá dar una solución técnica
    • Creará un caso de soporte conforme al comportamiento esperado
  • Esto también forma parte de las pruebas.

6. Registro de Resultados

Al finalizar cada caso de prueba, por favor llena las siguientes columnas en el archivo de UAT:

  • Resultado obtenido: Describe brevemente qué ocurrió
  • Estado:
    OK No OK OK con observaciones
  • Comentarios: Solo si algo no funcionó como esperabas

No es necesario adjuntar evidencia si el resultado es OK.

Importante

  • No todos los casos crean un caso en el sistema.
  • En algunos escenarios, los casos se crean solo con fines informativos y pueden no mostrarse al usuario.
